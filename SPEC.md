# AllegroScore Specification

## Overview
AllegroScore is an AI-assisted music composition application focused on classical score creation but flexible for any genre. It distinguishes itself by integrating a deeply embedded AI Agent that acts as a co-composer and tutor, assisting with music theory, stylistic adaptation, and rapid prototyping.

## Core Features
- **Cross-Platform**: Initial target is Linux, with future support for macOS, Windows, and mobile tablets (Android/iOS).
- **Score Editor**: A professional-grade music notation interface (similar to Sibelius).
- **AI Agent Chat**: A dedicated frame for interacting with the AI about the current composition.
- **Import/Export**: Support for MusicXML and Sibelius formats.
- **AI Capabilities**:
    - Style transfer (e.g., "make this sound like JS Bach").
    - Emotional/Cultural shifting (e.g., "make this sadder" or "more Eastern").
    - Error detection (voice leading, harmony, range).
    - Music theory explanation for all suggestions.
    - Automation (setting up staves, instrumentation).
- **Prototyping**: AI suggestions overlaid on the score in different colors for A/B testing and playback.
- **Playback**: Integrated high-quality synth/samples and MIDI support.

## Use Cases
- Refining melodies based on specific composer styles.
- Learning music theory through AI-explained recommendations.
- Harmonization assistance (e.g., string quartet in the style of Haydn).
- Structural assistance (lyrics to melody, counterpoint).
- Rapid setup and orchestration.
