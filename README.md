# AllegroScore - Music Composition Application

## Quick Start (Linux, including CachyOS)

```bash
# 1. Clone the repo
git clone git@github.com:durkimat/AllegroScore.git
cd AllegroScore

# 2. Build (one-time)
mkdir build && cd build
cmake ..
cmake --build . -j$(nproc)

# 3. Run
#    - Use -platform offscreen if you don't have a GPU/display
#    - Normal mode: just ./AllegroScore (needs Qt/X11/Wayland)
./AllegroScore -platform offscreen
```

## What You Get

- **Score Area** (left, ~70%): Renders MusicXML via Verovio/nanosvg
- **AI Chat Frame** (right, ~30%): Type a message + send to AI
- **API Key prompt** at top of chat frame - enter your OpenAI/Claude key once
- AI assists with: style adaptation, error checking, music theory explanations

## Controls

| Action | Key |
|---|---|
| Send AI message | Click **Send** button (or press Enter in input box) |
| Enter API Key | Top input field in chat frame (password mode) |
| Load custom score | (Future) File dialog to load MusicXML |

## Notes

- **First run**: You'll be prompted for an API key. This connects to your preferred LLM provider (OpenAI GPT-4o, Claude 3.5 Sonnet, etc.).
- **Offscreen mode**: Works without a GPU or display server (`-platform offscreen`).
- **Normal mode**: Remove the flag for X11/Wayland (ensure `qt6-x11extras` or `qt6-wayland` is installed).
- **Cross-platform**: Same build works on Linux, macOS, and Windows (Qt 6).

## Running on CachyOS

```bash
# Install Qt 6 if not present (CachyOS has it in repos)
sudo pacman -S qt6-base qt6-declarative qt6-network

# Build & run
git clone git@github.com:durkimat/AllegroScore.git
cd AllegroScore
mkdir build && cd build
cmake ..
cmake --build . -j$(nproc)
./AllegroScore -platform offscreen
```
